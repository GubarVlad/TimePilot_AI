03 / Reasoning Architecture

Collaborative Multi-Agent Critique Loop

TimePilot AI completely replaces fragile linear chains (A → B → C) with an iterative, self-correcting 4-agent state machine.

┌────────────────────────────────────────────────────────┐ │ User / Voice Request: "Urgent security audit at 14:00" │ └───────────────────────────┬────────────────────────────┘ │ ▼ ┌───────────────────────────┐ │ PlannerAgent │ (Scout Intent: Urgency 0.96) └─────────────┬─────────────┘ │ delegate ▼ ┌──────────────────┐ ┌───────────────────┐ │ Zetaris USL │◄─┤ ContextAgent │ (Queries calendar, backlog, │ & Meterless H-MEM│ └─────────┬─────────┘ and past episodic habits) └──────────────────┘ │ propose candidate slot: 14:00-14:45 ▼ ┌───────────────────┐ │ ConflictCritic │ [Audit slot against 6 events] └─────────┬─────────┘ │ [Collision with Team Sync?] ├─────────► [REJECT & DEMAND RETRY] │ Branch to ContextAgent (retry=1) │ Shift flexible UI task to 15:45 │ [APPROVED] ▼ ┌───────────────────┐ │ ReconcilerAgent │ ──► Execute mutations └───────────────────┘ ──► Commit H-MEM episode ──► Emit "Explain Why"
Why This Architecture Scores High
  • Context-Dependent Delegation: Planner delegates based on urgency and multi-dimensional intent.
  • Outputs Challenged & Revised: ConflictCritic rigorously tests candidate proposals against Zetaris Data Quality rules.
  • Dynamic Branching & Recovery: Overlaps trigger automatic retry loops with tighter constraints.
  • Auditable Traces: Every agent handoff, confidence score, and model name is logged to logs/agent_traces.jsonl.

05 / Sponsor Technology

Deep Integration: Zetaris & Meterless

Sponsor technologies are load-bearing architectural backbones, not cosmetic wrappers.

Zetaris Unified Semantic Layer DATA LAYER
  • 3 Federated Sources: Integrates calendar events, Jira/Linear task backlog, and user buffer preferences.
  • Active SQL Views: Offloads feasibility modeling to usl_cross_source_feasibility view.
  • 4 Automated Data Quality Rules: Pre-commit validation gates checking chronological ordering, pinned exclusivity, priority, and ID integrity.
  • Saves 70% Time: Semantic SQL views replaced over 300 lines of brittle custom Python filtering loops.
Meterless Engines & Nightshift ENGINES & GATEWAY
  • Meterless H-MEM Engine: 3-tier memory system with Working Memory (turn state), Episodic Memory (past shifts with recency decay), and Semantic Habits.
  • Habit Consolidation: Reinforces user preferences like morning focus bias and meeting buffer affinity over time.
  • Meterless Scout Intent Engine: Decomposes natural language into structured duration, time hints, and urgency scores.
  • Meterless Nightshift: Central OpenAI-compatible runtime connecting all agent LLM queries.
