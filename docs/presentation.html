Engineered with Sponsor Tech

DATA LAYER · FOUNDATIONAL
Zetaris Unified Semantic Layer (USL)

Eliminates fragmented intelligence by federating 3 disconnected silos:

  • src_calendar_events: Scheduled commitments, mobility, and pinned flags.
  • src_task_backlog: High-priority Jira/Linear engineering issues and estimates.
  • src_user_preferences: Work hours, 15-minute buffer rules, protected categories.
  • Semantic SQL Views: Feasibility calculation (usl_cross_source_feasibility) executed directly in SQL, saving 70% development time over custom Python loops.
  • 4 Automated Data Quality Rules: Pre-commit gates verifying chronological order, pinned exclusivity, valid priority, and identifier integrity.
ENGINES & GATEWAY
Meterless Engines & Nightshift

Provides human-like cognitive retention and intent extraction:

  • Meterless H-MEM Engine: 3-tier memory model: (1) Working Memory for turn candidate state, (2) Episodic Memory with recency decay, and (3) Long-Term Semantic Habits.
  • Habit Consolidation: Reinforces user preferences (morning focus bias, flexible task shifts) into persistent Bayesian weights without prompt tuning.
  • Meterless Scout Intent Engine: Decomposes complex natural language into urgency scores (0.0–1.0), durations, and slot parameters.
  • Meterless Nightshift: OpenAI-compatible AI provider gateway hosting model endpoints.
COMPUTE & SPEECH
NVIDIA Nemotron & Riva ASR

Specialized dual-model deployment and multilingual voice recognition:

  • Nemotron-3-super-120b: High-capacity reasoning engine driving Planner, Context, and Reconciler agents for deep synthesis.
  • Nemotron-3.5-lightning-30b: Low-latency evaluator powering ConflictCritic to audit calendar constraints in real-time.
  • NVIDIA Riva Parakeet ASR: Streaming multilingual speech-to-text (Parakeet-RNNT 1.1B) via gRPC for hands-free voice commands.
